# Pimentel LE5 - Integrated ASP.NET Core Web API & Angular Application

This repository contains the integrated backend and frontend projects for Lab Exercise 5.

## Project Structure

* **`PimentelLE2/`** — **Backend API & Database (Visual Studio 2022)**
  * Developed using C#, ASP.NET Core Web API, Dapper, and SQL Server.
  * Contains the `BlogAPI` project, `BlogDataLibrary`, and database stored procedures.

* **`frontend/`** (from `PimentelLE4`) — **Frontend Single-Page Application (VS Code)**
  * Developed using Angular v16 and TypeScript.
  * Connects to the ASP.NET Core Web API endpoints to perform user login, registration, and post management.
